# ほうきがでかすぎます！

指で左右に動かす、90秒のドタバタおそうじゲーム。スマートフォンの縦持ちブラウザ向け試作です。

**遊ぶ → https://sakusi1508.github.io/houki-too-big/**

## 操作
「おしごとをはじめる」から会話をタップで進めます。
廊下または画面下の操作エリアを触れて左右に滑らせると新人さんが動きます。指を離すと止まります。
大きなほうきは広く掃けますが、壁や家具に引っかかると掃除できません。先の家具を見て通り道を考えましょう。
右上で一時停止。別タブや別アプリに切り替えた場合も自動停止します。
PCではマウスドラッグ、A/D・矢印、Enter、Pも使えます。

## 記録
最高スコアは各ブラウザ内のlocalStorageに保存。サーバへのスコア送信・ログイン・共有ランキングはありません。
同じブラウザの利用者は記録を共有します。ブラウザの保存データを消すと記録も消えます。

## 配布
外部ライブラリや外部素材を読み込まない静的HTML/CSS/JavaScriptです。
GitHub Pagesでmainブランチのルートを公開する設定です。ゲームファイルの更新で再デプロイされます。
キャラクターと背景は仮の2D表現。音声・効果音は未実装。
Unreal版のSaveGamesや開発者の最高スコアは配布しません。
